Seção 1 · Arquitetura Multi-Tenant & Multi-Loja Genérica

1 Login Único para 1 ou N CNPJs (Troca Instantânea sem Deslogar)

No BeeBite, cada CNPJ ou unidade operacional é um registro isolado na tabela store (estoque, cozinha, impressoras e caixa próprios). Através da tabela associativa genérica user_store_access, o sistema se adapta automaticamente ao porte de qualquer cliente:

Perfil do Cliente no SaaS Retorno do /api/v1/auth/login Experiência na Tela (Celular e PC)
Cliente com 1 única loja (1 CNPJ) accessibleStores retorna 1 loja; JWT já entra nela. Zero complexidade: como accessibleStores.length === 1, o seletor de lojas fica oculto.
Cliente com 2+ lojas/CNPJs (ex: Delivery + Balcão ou Filiais) accessibleStores retorna todas as N lojas do proprietário. Sem deslogar: exibe o Store Switcher no topo. Ao clicar na outra unidade, chama POST /api/v1/auth/switch-store/{storeId} e troca o cookie JWT na hora sem pedir senha.
Funcionário de 1 unidade (ex: Caixa) accessibleStores retorna apenas a loja onde ele trabalha. Entra direto na unidade dele e não vê nem tem acesso às outras unidades do dono.
Seção 2 · Viabilidade & Topologia

Unidade Local Offline-First (EDGE) + Nuvem (CLOUD)

Padrão Store-and-Forward / Outbox

Qualquer loja cadastrada no BeeBite pode operar em modo CLOUD (direto na nuvem) ou em modo EDGE (servidor local na loja física + sincronização assíncrona via edge_sync_outbox).

Simulador Interativo de Arquitetura

Seções 3 & 4 · Operação Remota & Engenharia de Campo

Como Atualizar sem Ir ao Local (OTA) e os 6 Problemas Ocultos

1. Build & Registry
Docker + GHCR / Artifact Registry

Ao fazer git push na release, o GitHub Actions publica a nova imagem versionada (v1.2.0).

2. Janela de Madrugada
Watchtower às 04:00h

Cron 0 0 4 * * *: faz pg_dump preventivo, baixa a imagem nova, roda Flyway retrocompatível e reinicia fora do expediente.

3. Acesso de Emergência
Tailscale (VPN Mesh WireGuard)

Atravessa qualquer CGNAT de operadora gratuitamente. Você acessa via SSH privado (100.x.y.z) de casa para ver logs ou fazer rollback.

4.1. Mini-PC Dedicado Linux + Nobreak

Evita usar o Windows compartilhado do caixa. O computador do atendente abre apenas o navegador apontando para o IP local do Mini-PC.

4.2. Backup Criptografado Horário (R2 / GCS)

pg_dump + rclone enviando dumps para Cloudflare R2 (< R$ 1/mês) contra queima de SSD ou furto.

4.3. GraalVM Native + Device Token por Loja

Binário nativo (-Pnative) consome ~60MB de RAM e protege o código-fonte. O nó Edge usa apenas um token de sincronização restrito ao seu store_id.

4.6. Impressão Térmica na Unidade CLOUD (Delivery)

O TcpPrinterGateway conecta na porta 9100. Na unidade Delivery (Nuvem), o Tailscale Subnet Router no PC da expedição permite alcançar a impressora térmica local.

Seção 8 · Especificação Técnica de Implementação (TDD)

Migration V17, Use Cases e Endpoints (Multi-Store + Edge Outbox)

8.1. Migration SQL (V17__multi_store_and_edge_outbox.sql)

CREATE TABLE user_store_access (
    id          UUID        PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id     UUID        NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    store_id    UUID        NOT NULL REFERENCES store(id) ON DELETE CASCADE,
    role        VARCHAR(20) NOT NULL CHECK (role IN ('ADMIN','GERENTE','CAIXA')),
    permissions TEXT[]      NOT NULL DEFAULT '{}',
    created_at  TIMESTAMP   NOT NULL DEFAULT now(),
    CONSTRAINT uq_user_store_access UNIQUE (user_id, store_id)
);

INSERT INTO user_store_access (user_id, store_id, role, permissions)
SELECT id, store_id, role, permissions FROM users
ON CONFLICT (user_id, store_id) DO NOTHING;

ALTER TABLE store
    ADD COLUMN IF NOT EXISTS sync_mode VARCHAR(20) NOT NULL DEFAULT 'CLOUD' CHECK (sync_mode IN ('CLOUD', 'EDGE')),
    ADD COLUMN IF NOT EXISTS edge_api_key_hash VARCHAR(255),
    ADD COLUMN IF NOT EXISTS last_edge_sync_at TIMESTAMP;

CREATE TABLE edge_sync_outbox (
    id              UUID         PRIMARY KEY DEFAULT gen_random_uuid(),
    store_id        UUID         NOT NULL REFERENCES store(id) ON DELETE CASCADE,
    event_type      VARCHAR(60)  NOT NULL,
    aggregate_id    UUID         NOT NULL,
    payload         JSONB        NOT NULL,
    status          VARCHAR(20)  NOT NULL DEFAULT 'PENDING' CHECK (status IN ('PENDING', 'SYNCED', 'FAILED')),
    attempts        INTEGER      NOT NULL DEFAULT 0,
    last_error      TEXT,
    created_at      TIMESTAMP    NOT NULL DEFAULT now(),
    synced_at       TIMESTAMP
);

CREATE TABLE edge_synced_event_log (
    event_id        UUID         PRIMARY KEY,
    store_id        UUID         NOT NULL REFERENCES store(id) ON DELETE CASCADE,
    event_type      VARCHAR(60)  NOT NULL,
    aggregate_id    UUID         NOT NULL,
    received_at     TIMESTAMP    NOT NULL DEFAULT now()
);
